# P2 H5

`P2` is the new H5 architecture workspace.

Principles:

- no `iframe`
- no `srcdoc`
- no `postMessage` routing
- one router
- one app shell
- one state layer

Local run:

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```

Current status:

- this is a minimum runnable scaffold
- UI reproduction from `P1` starts from here
